- 스킬 업데이트 결과에서 갱신 완료, 최신 상태, 수정 파일 충돌, 업데이트 건너뜀, 실행 실패를 구분하고 파일 수와 다음 작업을 안내합니다.
- 제품 이름과 도구 선택이 유효하면 오래되었거나 잘못된 릴리스 설정이 있어도 스킬을 업데이트할 수 있습니다. 업데이트는 설정 파일을 변경하지 않으며, 콘텐츠 명령에는 여전히 유효한 설정이 필요합니다.
- `releasekit init`을 다시 실행하면 프로젝트의 다른 설정을 유지하면서 사용할 에이전트 도구를 변경할 수 있습니다.
- `releasekit preview <version>`으로 원하는 릴리스를 로컬에서 미리 볼 수 있습니다.
- 내보내기는 기본적으로 연결된 릴리스 이력 전체를 포함합니다. 개수를 제한하려면 `--limit N`을 사용합니다. 기존 설정에서는 콘텐츠 명령을 실행하기 전에 더 이상 사용하지 않는 `history.limit` 항목을 제거해야 합니다.
- 릴리스 날짜에 시간과 시간대를 함께 저장해 같은 날의 릴리스도 기록된 시각을 유지할 수 있습니다.
